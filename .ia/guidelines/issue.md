# Issue

## Summary

Descreva de forma breve e objetiva a necessidade, problema ou melhoria proposta.

## Context

Explique o cenário atual e por que esta alteração é necessária.

Inclua informações que ajudem outros contribuidores a entenderem o contexto e o impacto da implementação.

## Proposed Solution

Descreva, caso aplicável, uma possível abordagem para resolver a issue.

> Esta seção não precisa definir a implementação final. Outras abordagens podem ser discutidas durante o desenvolvimento.

## Acceptance Criteria

* [ ] O comportamento esperado foi implementado.
* [ ] Os cenários principais foram validados.
* [ ] Os testes necessários foram adicionados ou atualizados.
* [ ] A documentação foi atualizada, quando necessário.
* [ ] A implementação segue os padrões definidos pelo projeto.

## Additional Information

Adicione qualquer informação que possa ajudar na implementação:

* Screenshots
* Logs
* Referências
* Documentações
* Exemplos
* Discussões relacionadas

## Definition of Done

* [ ] Implementação concluída.
* [ ] Testes passando.
* [ ] Code review realizado.
* [ ] PR relacionado à issue.
* [ ] Sem regressões conhecidas.
